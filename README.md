# MARCUS BOOK STORE – Online Book Store

A React-based online bookstore frontend with Home, Books, About, Contact, Login, Sign Up, Cart, and Checkout pages. Cart and demo account data are stored in the browser's LocalStorage; no backend or database is required.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:3000`).

## Production build

```bash
npm run build
npm run preview
```
